# bog Wiki

A small, offline reference for things that come up while running bog - the stuff that's easy to forget between installs, or that only comes up once every year or two.

This wiki ships inside the OS itself and is rebuilt on every update, so it stays in sync with whatever version of bog you're running. No network connection is needed to read it, if you need to access it away from your system you can visit it [here](https://github.com/chrislowles/bog).

## Sections
* [Storage & Drives](storage.html) - Storage scenarios: adding a secondary drive, and getting it into Steam, among other things.
* [Flatpak Filesystem Access](flatpak.html) - granting sandboxed apps access to specific folders and drives, and automount gotchas.
* [Keeping bog Tidy](maintenance.html) - updates, cleanup, pinning apps, and rolling back if something breaks.

If you think of something that belongs here, it's just markdown under `/usr/share/bog/wiki/src` in the [bog repo](https://github.com/chrislowles/bog).
